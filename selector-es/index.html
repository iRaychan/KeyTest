Automatic duty sizing uses the next higher 5 mm. You can then adjust the impeller by 1 mm or type any whole-mm value within the model Min / Max range.

System Curve
Static head + calculated friction resistance. The curve starts at Static Head and passes through Required Duty D1.
Orifice
The orifice formula calculates friction loss only. After-orifice head = Pump Head − Orifice Friction Loss.
Selection can evaluate up to 6 total-system duty points. For each point, per-pump flow = total flow ÷ running pumps.
