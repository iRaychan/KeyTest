KeySuite V2.16 Installation
===========================

Existing V2.15 deployment
-------------------------
1. Back up the current deployment.
2. Extract KeySuite_V2.16_Changed_Files_Patch.zip over the V2.15 files.
3. Keep the existing working config.js.
4. No Supabase migration is required.
5. Deploy and hard refresh with Ctrl + Shift + R.

Clean installation
------------------
Use KeySuite_V2.16_GitHub.zip and retain/configure the required config.js for the target deployment.
