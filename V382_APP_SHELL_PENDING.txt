KeySuite V3.8.2 R2 — APP-SHELL INTEGRATION NOTE

The exact full KeySuite V3.8.1 parent app shell was not available in this build session. The public KeyTest shell visible during the build is older (V3.6), so it was intentionally NOT copied over V3.8.1.

The formerly pending parent-shell amendments are now supplied without replacing index.html/app.js:

1. Dashboard Quick Pump Selection
   - Flow + Head input.
   - Live CHC and ES duty checks.
   - Show only suitable product families.
   - Expand family -> recommended model -> pump details.

2. KeyCore Full-Screen Mode
   - Hide normal left panel while KeyCore is active.
   - Use the full available page/canvas.

3. KeyCore > Product
   - Opens Product Hub first instead of CHC directly.

4. KeyCore > Pump Curve
   - Opens Pump Curve Hub first instead of CHC directly.

IMPLEMENTATION
- v382-dashboard-keycore.js contains the parent-shell extension.
- sw.js injects the extension into KeySuite navigation HTML at runtime using the current service-worker scope.
- This avoids downgrading unknown V3.8.1 app-shell changes.
- After deployment, hard refresh twice or restart the installed PWA so the new service worker takes control.
