KeySuite V3.00 Changes
======================

Coupling Detail Layout Correction
---------------------------------
- Keeps Selected Type, Resolved Model and F/H Arrangement in an aligned desktop row.
- Moves the resolution message into its own full-width row below the controls.
- Places Pump and Motor bush information below the resolution message.
- Removes the Coupling-specific z-index/position interaction that allowed fields
  to cover the resolution message.
- Makes Coupling input rows use the same 42 px control height as their grid row.
- Allows long messages to wrap and lets the Coupling card expand with its content.
- Uses two columns on medium screens and one column on narrow screens.

Release
-------
- Visible KeySuite version updated to V3.00.
- Local script cache keys updated to v=300.
- Service-worker cache updated to keysuite-v300.
- Manifest name updated to KeySuite V3.00.
- No database migration.
