KeySuite V2.15 Installation
===========================

Existing V2.14 deployment
-------------------------
1. Back up the current deployment.
2. Extract KeySuite_V2.15_Changed_Files_Patch.zip over the V2.14 files.
3. Keep the existing working config.js.
4. No Supabase migration is required.
5. Deploy and hard refresh with Ctrl + Shift + R.

Clean installation
------------------
Use KeySuite_V2.15_GitHub.zip and retain/configure the required config.js for the target deployment.
