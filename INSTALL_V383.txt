3. Upload the full extracted repository contents to GitHub, preserving folders.

6. No KeyAI Edge Function redeployment is required for V3.8.3.
7. Wait for GitHub deployment to finish.
8. Open KeySuite and press Ctrl+F5.
9. If installed as a PWA, close and reopen once so service worker cache keysuites-v383-full takes control.
